# portfolio-chatbot

This repo is a public template. Anyone can copy it to build their own chatbot.

- Never add personal information: no real names, emails, phone numbers, account names, website addresses or business data.
- Use placeholder values only, like `YOUR_USERNAME`, `hello@example.com` or the sample "Alex Chen" profile in `setup/examples/`.
- Real profile files go in `setup/`, which is gitignored. Never commit them.
- Keep the worker names generic: `portfolio-chatbot-worker` and `portfolio-chatbot-widget`.
